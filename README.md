# 3D-Tycoon
Making 3d Tycoon game

Controlls:
W: Foward
A/D Left/ Right
S: Back

Space: jump

E: Pickup
R: Let go

(While holding) 
T: Move Back
R: Move Forward

The game doesn't have a TON of things to do other than pick up a conveyor and move it around; however, it took me a LONG time to make. Why?
Well, because I wanted to make a conveyor without lists.

While I couldn't finish the game, I did learn many things, such as

- multiple Raycasting
- Better knowledge of Unity's physics.
- Pickup/ Let go sytem
- Lists

Raycasting:
I learned how to make multiple raycasts and check them with a for loop.

Unity's physics:
I learned how to make an object go in the direction of another object using transform. forward.

Pickup/Let Go:
This is my favorite thing I made Since it  feels very smooth with how it works.

Lists:
I leanred how to use these, and it feels like a game changer, this is becasue when working with collisions I thought you could only do one object at a time. However I now know that you
can just use a list!
